How every page works

Each topic is one self-contained HTML file. The tabs run from simple to detailed, and every view reads the same steps, so switching keeps your place.

High level

The big picture in plain language, with everyday comparisons. No background needed.

Interview

The answer an engineer would give: protocols, sequences, layers and trade-offs, in several visual styles.

Deep internals

Bytes on the wire, kernel and firmware internals, and what the hardware is doing.

Controls on every page: ← → step through, Space pauses the animations, and Auto-advance runs a looping tour.

Plain HTML, CSS and JavaScript: no build step, no tracking. Fonts load from Google Fonts. Addresses and timings in the examples are illustrative.
